# Project 14: 銀行間取引データ処理システム (C言語/Socket通信)

## 1. 概要と目的

本プロジェクトは、C言語を用いて**ソケット通信**と**マルチスレッド**を組み合わせた、銀行間の取引処理シミュレーションシステムです。

2つの異なる銀行（プロセス）間で発生する大量のトランザクションデータを並行処理し、データの整合性を保ちながら高速に送金・受金処理を行うことを目的としています。また、Raspberry Pi（組み込み環境）でのクロスコンパイルと動作検証も実施しました。

## 2. 使用技術

* **言語:** C言語
* **OS/環境:** Linux, Raspberry Pi
* **並行処理:** POSIX Threads (`pthread`) - マルチスレッドによる高速化
* **同期制御:** Mutex (`pthread_mutex`) / Condition Variables (`pthread_cond`) - 排他制御によるデータ整合性の確保
* **ネットワーク:** TCP/IP Socket (`socket`, `bind`, `listen`, `accept`) - プロセス間通信
