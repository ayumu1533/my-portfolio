# データ構造と探索アルゴリズム

本ディレクトリには、大学2年次のデータ構造およびアルゴリズムの授業で作成したC言語プログラムが含まれています。二分探索木、ハッシュ表（チェイニング法）、および幅優先探索（BFS）といった、基本的なデータ構造と探索アルゴリズムの実装例です。

## プログラム詳細

### 1. 二分探索木 (BST) プログラム (`./class3-C/p45.c`)

**目的:** 二分探索木（BST）の基本構造を理解し、値の挿入、構造の検証といった操作を再帰的に実装する。

#### データ構造

* `struct node`: 値（`value`）と左右の子ノードへのポインタ（`left`, `right`）を持つノード構造体。


#### 主要な機能

| 関数名 | 概要 | 強調点 |
| :--- | :--- | :--- |
| `read_tree` | ユーザー入力（例: `<1,2,3>`）に基づき、**初期の木構造を再帰的に生成**する。 | |
| `check_bt` | 厳密なBSTの条件（左の子孫の値 $<$ 根の値 $<$ 右の子孫の値）を満たしているか再帰的に検証する。 | **構造の厳密な検証** |
| `insert_bt` | 乱数をBSTの規則に従って挿入し、そのノードが根から何階層目（`depth`）に挿入されたかを計測する。 | **挿入と深さ計測** |
| `print_tree` | 木構造を `<左の子, 根の値, 右の子>` 形式で出力する。 | |

---

### 2. ハッシュ表 (チェイニング法) プログラム (`./class3-C/p57.c`)

**目的:** ハッシュ表を用いたデータの高速な登録、検索、削除の仕組み（特に衝突解決としてのチェイニング法）を実装する。

#### データ構造

* `struct item`: 単語（`word`）と出現回数（`count`）を保持する構造体。
* `hashtable[256]`: ハッシュ表本体（配列）。同じハッシュ値を持つ要素は**連結リスト（チェイニング）**で処理されます。


#### 主要な機能

| 関数名 | 概要 | 強調点 |
| :--- | :--- | :--- |
| `chainhash` | テキストファイルから単語を読み込み、ハッシュ関数でインデックスを計算。単語が既にあれば `count` を増加、なければ新規にノードを作成しリストの先頭に追加。 | **単語の登録・出現回数カウント** |
| `delete_item` | ユーザー入力に対応する単語をハッシュ表から検索し、連結リストから削除する。 | |
| `dump_ht` | ハッシュ表の全バケットを巡回し、登録されている全ての単語と出現回数を一覧出力する。 | |

### 3. 迷路探索 (BFS) プログラム (`./class3-C/p7E.c`)

**目的:** 幅優先探索（BFS）アルゴリズムを実装し、2次元配列で表現された迷路のスタートからゴールまでの最短経路を特定する。

#### データ構造

* **キュー (Queue)**: 配列とポインタ（`q_head`, `q_tail`）で実装され、探索すべきマス目を管理します。
* `struct node`: 経路の長さ（`length`）と座標（`x`, `y`）を持つ構造体。


#### 主要な機能

| 機能 | 概要 | 強調点 |
| :--- | :--- | :--- |
| **最短経路探索** | キュー (`enqueue`/`dequeue`) を用いて、**距離が近い順に**隣接する道 (`0`) を探索（**BFS**）する。 | **幅優先探索 (BFS)** |
| **最短距離の計算**| ゴールに到達したノードの `length` の値が最短距離となる。 | |
| **最短経路の表示**| `make_shortest` 関数により、最短経路上のマス目の配列値を変更し、`print_board` 関数で「〇」として迷路図上に出力する。 | **結果の可視化** |
