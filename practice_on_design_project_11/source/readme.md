# 1. 概要
## 本プロジェクトについて
「ジグリズム（JigRhythm）」 は、グッパーの手のジェスチャーと、貧乏ゆすりを応用した足のジグリング動作を組み合わせたリズムゲームです。
高齢者をターゲットとし、リズムゲームと身体動作を結びつけることで、認知機能と身体機能の両方を楽しみながら鍛えることを目的としています。

# 2. 実行手順
※カレントディレクトリを practice_on_design_project_11 にしてください。

Arduino IDE を開き、以下のファイルを開いてください。

<pre>
practice_on_design_project_11/source/arduino_BNO085/arduino_BNO085.ino
</pre>

tool->Board->Arduino UNO R4 Board->Arduino UNO R4 Minimaを選択してください。

1台IMU装置を接続し、そのCOM番号を確認してください。こちらが右足用となります。verify、uploadをしてください。

書き込みが終わったら、随時シリアルモニターで動作を確認してください。（START後、IMUを振ると"1"が表示されます。）

1台目のIMU装置を外し、同様にもう一台のIMU装置を接続してください。COM番号を忘れず確認してください。こちらが左足用です。

以下の部分を修正して、保存してください。

<pre>
137行目　修正前　Serial.println("1");
　　　　 修正後　Serial.println("2");
</pre>

修正後、verify、uploadをしてください。

2台目も同様に、書き込みが終わったら、随時シリアルモニターで動作を確認してください。（START後、IMUを振ると"2"が表示されます。）

IMUをそれぞれ接続してください。

VScodeを開き、main.pyを次のコマンドにより実行してください。

使用方法：
```
rye run python -m source.main --right <右足につけたセンサのCOMポート番号> --left <左足につけたセンサのCOMポート番号>
```

もし上手くIMUが起動しない場合、下のコマンドを実行してください。
<pre>
rye run python source/arduino_IMU_module.py --right <右足につけたセンサのCOMポート番号> --left <左足につけたセンサのCOMポート番号>
</pre>

右足のIMUと左足のIMUを動かすと右足アクティブ、左足アクティブとコマンドに出てくるようにしています。接続状況を確認するために使用してください。

# 3. ゲームの遊び方

実行するとゲームの初期画面が開きます。「はじめる」というボタンを押すと遊び方の画面になります。遊び方を読んで準備ができたらクリックします。3/2/1というカウントダウンの後にリズムゲームが開始されます。

両手両足を使ってノーツが降りてきて線の上を通る瞬間、手はグーにして、足は上にあげます。

# 4. 各ファイルの説明
## IMU用のArduinoプログラム
### arduino_BNO085.ino
この Arduino プログラムは BNO085 IMU センサを使用し、Python 側のリズムゲームに向けて 足の動作を検出して送信する役割を持っています。

主な機能：
- Adafruit_BNO085 ライブラリを使用してセンサを I2C で初期化
- 利用する測定モード（加速度 / ジャイロ / クォータニオン / オイラー角）を選択可能


## PC側の各プログラム
### arduino_IMU_module.py
Arduino UnoとPCをシリアル通信で接続し，IMUのデータを取得するプログラムです。
他のスクリプトからモジュールとして読み込むことが出来ます。

このモジュールは、Arduino UnoとPCをシリアル通信で接続し、IMUセンサーからのデータを取得するためのPythonクラスを提供します。

主な機能：
- Arduinoとのシリアル接続の確立と管理
- データストリーミングの開始・停止制御
- 取得したデータの簡易的な処理

使用方法：
```
rye run python source/arduino_IMU_module.py --right <右足につけたセンサのCOMポート番号> --left <右足につけたセンサのCOMポート番号>
```
実行スクリプトとして呼び出した場合，IMUから正常にデータが送信されているか確認することができます。

`Ctrl+C`でプログラムを終了

### game.py

`main.py` から呼び出され、Pygameを用いてゲーム画面（UI、ノーツ）を生成・制御するコアモジュールです。

**主な機能**
* **入力処理の統合**
    * **ハンドトラッキング**: 別プロセス (`gesture_processor.py`) からキュー経由で受け取るジェスチャー情報（グー・パーなど）を処理。
    * **IMUセンサー**: `ArduinoIMUModule` を介してArduinoから足の動き（貧乏ゆすり動作）を取得。
    * **キーボード**: デバッグおよび補助入力。
* **ゲーム進行管理**
    * タイトル画面、カウントダウン、メインゲームループの制御。
    * 譜面データ (`chart_easy.json`) の読み込みとノーツの生成。
    * 判定ロジック（Perfect/Good/Miss）とスコア・コンボ計算。
* **ビジュアル描画**
    * センサー入力に連動して動くアバター（手足）の描画。
    * 判定エフェクトやUIのレンダリング。

### gesture_processor
MediaPipe の Gesture Recognizer（手指ジェスチャー認識モデル）を用いて、
カメラ映像からリアルタイムで手のランドマーク（21点の位置）とジェスチャーを検出し、
マルチプロセス経由でゲーム側へ送信するためのプログラムです。
本スクリプトは サブプロセスで動作し、メインゲームとは独立してジェスチャー認識を行います。
検出したジェスチャーは Queue を通じてメインプロセスに送られ、ゲーム操作に利用されます。

主な機能：
- MediaPipe Gesture Recognizer モデルの読み込み
- Web カメラからのリアルタイム映像処理
- 手のランドマーク検出（最大2手）
- ジェスチャー（グー・パー・ピースなど）の分類
- 独自の「グー → パーまで連続禁止」ロジックの実装

### handtracking_util.py
MediaPipe Hands を使った「手のランドマーク処理」「手IDの追跡」「描画処理」をまとめたユーティリティモジュールです。
ゲーム本体やジェスチャー認識処理から呼び出され、手の位置情報の安定取得や可視化を担当します。

主な機能：
- 手のランドマークの取得・前処理
- 手 ID の追跡（左右の判定とは別の ID 管理）
- ランドマークの描画処理（デバッグ用）
- CSV 保存用フォーマットの構築

### main.py

このアプリケーションのエントリーポイント（起動ファイル）です。

主な役割は、「Pygameのゲーム本体」(`game.py`)と「MediaPipeのハンドトラッキング」(`gesture_processor.py`)という2つの重い処理を、別々のプロセスとして起動・管理することです。

処理の流れ：

  * `multiprocessing.Queue`を作成し、プロセス間の通信（ジェスチャー情報の受け渡し）を準備します。
  * `gesture_processor.py`をサブプロセスとして起動し、ハンドトラッキングを開始させます。
  * `game.py`をメインプロセスとして起動し、ゲームを開始します。
  * ゲームが終了すると、`finally`ブロックでサブプロセスを安全に`terminate()`（停止）させ、リソースを解放します。

使用方法：

```
rye run python -m source.main --right <右足につけたセンサのCOMポート番号> --left <左足につけたセンサのCOMポート番号>
```

このスクリプトは、ゲーム全体を起動する親プロセスとして機能します。引数は必要ありません。
